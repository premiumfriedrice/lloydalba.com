# Thoughts

Drop a markdown file in this folder to publish a thought.

- Filename: `YYYY-MM-DD-your-title.md` (becomes the URL slug)
- Frontmatter: `title` and `date`
- Body: any markdown

Example:

    ---
    title: On building in public
    date: Mar 2026
    ---

    The body of the thought.
